# Cursos de español A1–B1 · самостоятельные интерактивные курсы

Полные курсы испанского языка для самостоятельной работы: **A1**, **A2** и **B1**.
Чистый HTML + CSS + ванильный JavaScript, без сборки, зависимостей и серверной части.
Озвучка — встроенный голос браузера (`speechSynthesis`), поэтому аудиофайлы и интернет не нужны.

## Курсы

| Уровень | Название | Папка | Объём |
|---|---|---|---|
| A1 | Primeros pasos · Первые шаги | `curso-espanol-a1/` | 11 модулей · 49 уроков · 343 задания · 16+2 недели |
| A2 | Nuevo ritmo · Новый ритм | `curso-espanol-a2/` | 11 юнитов · 45 уроков · 270 заданий · 22+2 недели |
| B1 | Rumbo a la autonomía · Курс на самостоятельность | `curso-espanol-b1/` | 13 юнитов · 50 уроков · 300 заданий · 44+4 недели |

Главная страница репозитория — [`index.html`](index.html), с неё открываются все три курса.
Из любой страницы курса (урок, главная курса, экзамен) в верхней панели и в подвале
есть ссылка **«← Все курсы»** на общую главную.

## Что внутри каждого курса

- `index.html` — методика, программа по юнитам, календарный график, ресурсы, прогресс;
- `leccion-01.html` … — по одной странице на урок;
- `examen-a1.html` / `examen-a2.html` / `examen-b1.html` — итоговый экзамен и чек-лист CEFR;
- `style.css`, `app.js`, `exercises.js` — оформление, прогресс (localStorage) и движок заданий с автопроверкой;
- `README.md` — подробное описание методики курса.

## Анатомия урока

Новые слова (каждое с озвучкой) → лексический тренажёр → грамматика → грамматический тренажёр →
«Sonidos y letras» → чтение → аудирование → говорение → «Situación real» (диалог с режимом собеседника) →
письмо-ДЗ. В уроке 0.1 есть блок «El alfabeto» — 27 букв с озвучкой.

- 7 интерактивных заданий на урок, 7 разных типов, автопроверка кнопкой «Comprobar»;
- лучший результат и отметки сохраняются в браузере (localStorage, ключи с префиксом `a1-` / `a2-` / `b1-`);
- тумблер «Перевод» в шапке показывает русский перевод примеров, текстов, аудио и вопросов;
- ввод нормализуется: регистр и ударения проверяются мягко.

## Локальный просмотр

Просто откройте `index.html` в браузере. Для корректной работы прогресса и озвучки
рекомендуются Chrome / Edge / Safari. Возможен локальный сервер:

```
python3 -m http.server 8000
```
