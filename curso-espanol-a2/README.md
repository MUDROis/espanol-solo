# Curso de español · Nivel A2 — «Nuevo ritmo»

Полный интерактивный курс испанского языка уровня A2 для самостоятельной работы: 11 юнитов, 45 уроков с лексикой, грамматикой, чтением, аудированием, говорением и письмом, 270 интерактивных заданий с автопроверкой, итоговый экзамен и чек-лист CEFR.

## Структура

- `index.html` — главная страница: методика, программа курса, календарный график, ресурсы, прогресс.
- `leccion-01.html` … `leccion-45.html` — уроки (по одной странице на урок).
- `examen-a2.html` — итоговый экзамен и чек-лист CEFR.
- `style.css`, `app.js`, `exercises.js` — оформление, прогресс (localStorage) и движок заданий с автопроверкой.

## Анатомия урока

Девять шагов в одном порядке: новые слова с озвучкой → лексический тренажёр → новая грамматика (карточки) → грамматический тренажёр → чтение с вопросами → аудирование с автопроверкой → говорение вслух → реальная ситуация (диалог с озвучкой) → письмо (домашнее задание).

- В каждом уроке 6 интерактивных заданий: 7 типов (соединить пары, вписать, выбор, список, собрать фразу, верно/неверно, сортировка) — типы меняются от урока к уроку.
- Автопроверка кнопкой «Comprobar», показ ответов, лучший результат сохраняется в браузере (localStorage).
- Аудирование озвучивается встроенным голосом браузера (speechSynthesis, испанский голос): кнопки «Слушать» и «Медленно», подсветка текущей фразы, транскрипт. Файлы аудио не нужны.
- Ввод текста нормализуется: регистр и ударения проверяются мягко (совпадение без тильд считается верным с пометкой).

## Перевод

В шапке каждого урока есть тумблер «Перевод». Он показывает русский перевод:

- примеров к каждому новому слову (таблица «Новые слова»);
- примеров в карточках грамматики;
- абзацев текста для чтения и строк аудирования;
- вопросов и вариантов ответов во всех заданиях.

Состояние тумблера сохраняется в браузере: если включить его один раз, переводы будут показываться и в следующих уроках. По умолчанию перевод скрыт — рекомендация: сначала проходите материал без подсказок, перевод используйте для самопроверки и разбора ошибок.

## Локальный просмотр

Просто откройте `index.html` в браузере. Для корректной работы прогресса и озвучки рекомендуются Chrome/Edge/Safari. Возможен локальный сервер: `python3 -m http.server 8000` в папке курса → <http://localhost:8000>.

## Деплой

Загрузите содержимое папки как есть — любая из опций ниже работает без настроек:

- **GitHub Pages**: репозиторий → Settings → Pages → deploy from branch (корень или `/docs`).
- **Netlify**: перетащите папку в Netlify Drop (app.netlify.com/drop).
- **Vercel**: `vercel deploy` в папке курса (framework preset — Other).
- **Cloudflare Pages**: создайте проект и загрузите папку напрямую.

Файлы не требуют серверной обработки: чистый HTML + CSS + ванильный JavaScript.
